# ManaCollector

A free Windows desktop app for Magic: The Gathering decks, collections and wishlists, by Rodrigo Flores Salinas.

[Download the latest release](https://github.com/goron16/ManaCollector-Releases/releases/latest). Use **ManaCollector_v44_Setup.exe** for installation, optional desktop and Start menu shortcuts, and an uninstaller. **ManaCollector_v44_Windows.zip** is the portable alternative. Windows 10 or later, 64-bit; Python and required libraries are included.

## Features

- Shared list and artwork views with up to six columns, search, sorting, grouping and detailed filters.
- Commander area, exact printing and finish selection, saved decks, collections and wishlists.
- Import and export, local artwork and price caches, and offline access to previously downloaded content.
- Optional startup update checks, verified downloads, and preservation of the user library during upgrades.

## Optional support

This release is already ad-free. No advertising SDK is active.

[Support development on Ko-fi](https://ko-fi.com/goronsan). In the app, choose **Support on Ko-fi**, copy the generated reference into the payment message, and make a **one-time tip of at least US$5** to activate one calendar month without ads. Activation is saved locally for offline use. Recurring subscriptions, commissions and shop orders do not qualify. Ko-fi's test notification reached the connected service successfully; a real paid transaction has not been tested.
